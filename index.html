#1

2D Spaceship Game

Qt Creator · C++

Teamprojekt · 2 Personen

Kurzer Gameplay-Ausschnitt – die technische Erklärung steht daneben.

Das Spiel entstand als Projekt in einer Zweiergruppe. Der Spieler steuert ein Raumschiff, weicht Asteroiden und Gegnerprojektilen aus und reagiert auf Ereignisse, die teilweise über einen TCP-Server an den Client geschickt werden.

Mein Teil im Projekt

  • Spielersteuerung und Bewegung
  • Kollisionen
  • Soundeffekte und Teile des Audio-Systems
  • UI und visuelle Elemente
Code auf GitHub YouTube

Wie das Projekt funktioniert

1. Serversendet Befehle wie Spielstart, Gegner-Events oder Werte für Geschwindigkeit und Asteroiden.
2. Network-Klasseempfängt die Daten über QTcpSocket, puffert sie und zerlegt die Textbefehle.
3. Signals & Slotsgeben die empfangenen Events an das eigentliche Spielfenster weiter.
4. Game LoopTimer aktualisieren Bewegung und Gameplay; QPainter zeichnet Spieler, Gegner und Projektile.
5. Multimediaseparate Klassen kümmern sich um Musik, Soundeffekte und die Video-Hintergründe.

#2

Unity Movement Prototype

Unity · C#

Eigenes Movement-System

Kurzer Gameplay-Ausschnitt – die technische Erklärung steht daneben.

Bei diesem Unity-Projekt habe ich besonders viel Zeit in das Movement gesteckt. Ich wollte nicht einfach einen fertigen First-Person-Controller übernehmen, sondern selbst verstehen, wie Bewegung, Rigidbody-Physik, Kamera und Gun Sway zusammenarbeiten. Das Ziel war, dass sich die Bewegung möglichst flüssig anfühlt.

Woran ich gearbeitet habe

  • Walking, Sprinting, Jumping und Crouching
  • Sliding mit eigener Momentum-Logik
  • Bewegung auf normalen Flächen, in der Luft und auf Gefällen
  • Raycasts, damit der Spieler unter Hindernissen nicht einfach aufsteht
  • Mouse-Look und FOV-Wechsel beim Sprinten
  • Gun Sway beim Drehen und seitlichen Bewegen
Code auf GitHub YouTube

Wie das Movement aufgebaut ist

1. InputUpdate() liest Tastaturzustände und entscheidet, ob der Spieler läuft, sprintet, springt, croucht oder slidet.
2. PhysikFixedUpdate() wendet die eigentlichen Kräfte auf den Rigidbody an.
3. Ground / Air / SlopeRaycasts prüfen Boden und Gefälle. Auf Slopes wird die Bewegungsrichtung auf die Fläche projiziert.
4. SlidingAuf Gefällen baut sich zusätzliche Kraft auf. Auf flachem Boden nimmt sie wieder ab.
5. Kamera & WaffeKamera-FOV und Gun Sway reagieren auf Bewegung und Sprint-Zustand und werden weich interpoliert.

#3

Vitrometer

HTML · CSS · JavaScript

Webprojekt

Das Vitrometer ist eine kleine Webseite für Widerstandswerte. Man wählt die vier Farbringe aus und die Seite berechnet daraus den Wert. Gleichzeitig werden die Balken auf der Widerstandsgrafik passend eingefärbt.

Wie es funktioniert

  • Die Dropdowns liefern die Werte der ausgewählten Farbringe
  • JavaScript liest die Auswahl mit getElementById() aus
  • Multiplikator und Toleranz werden über Arrays zugeordnet
  • Der berechnete Wert wird direkt im DOM ausgegeben
  • Die vier Balken der Grafik bekommen dynamisch die ausgewählten Farben

#4

Filmdatenbank

COBOL · CRUD

Konsolenprogramm
data-program.cbl
access-film section.
    read film-data
    perform handle-error-messages

    if status-ok
        display "FILM-ID: "
          film-number of film-data
        display "NAME: "
          film-name of film-data
        display "ERSCHEINUNGSDATUM: "
          film-release-year of film-data
    end-if.

Die Filmdatenbank habe ich in COBOL gebaut. Die erste Version hat die Filme nur in einer Tabelle im Arbeitsspeicher gehalten. Danach habe ich sie zu einer Version mit einer indexierten Datei erweitert, damit die Daten auch nach dem Beenden gespeichert bleiben.

Was die spätere Version kann

  • Filme anlegen, lesen, ändern und löschen
  • Speicherung in einer Indexed File
  • Filmnummer als Record Key; Name und Jahr als alternative Keys
  • Sortierung nach Name oder Erscheinungsjahr
  • Filtern nach einem oder zwei Schauspielern
  • Prüfung auf doppelte Filmnummern und Namen
  • Behandlung verschiedener File-Status-Codes
Code auf GitHub

Grundidee der Datenbank

1. MenüDer Benutzer wählt eine Aktion wie Anzeigen, Ändern, Einfügen, Löschen, Sortieren oder Filtern.
2. SchlüsselEin Film wird über seine Filmnummer angesprochen; Name und Jahr können als alternative Schlüssel verwendet werden.
3. DateiREAD, WRITE, REWRITE und DELETE arbeiten direkt mit der indexierten Datei.
4. FilterBei der Schauspielersuche werden die Actor-Felder eines Films durchlaufen und mit der Eingabe verglichen.
